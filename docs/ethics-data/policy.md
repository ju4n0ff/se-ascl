# Política de Datos y Ética — SeñasCL

## Principios
1. **Privacidad por diseño:** El video procesado nunca sale del dispositivo
2. **Consentimiento informado:** Explícito, específico y revocable
3. **Mínimo necesario:** Solo recolectar datos necesarios para la función
4. **Transparencia:** El usuario sabe siempre qué se procesa y dónde

## Datos biométricos
Los landmarks de manos/rostro son datos biométricos. Se tratan con el mismo cuidado que datos sensibles de salud.

## Consentimiento para captura de datos
Para cualquier recolección de video/landmarks para entrenamiento:
- Consentimiento escrito por cada persona grabada
- Si es menor de edad, consentimiento de representante legal
- Indicar: uso, tiempo de retención, con quién se comparte
- Derecho a retiro del consentimiento en cualquier momento

## Leyes aplicables
- **Ley 19.628:** Protección de datos personales
- **Ley 21.719:** Protección de datos personales (2024)
- **Ley 20.422:** Derechos de personas con discapacidad
- **Ley 21.303:** Reconocimiento oficial de LSCh

## Almacenamiento
- Datos de entrenamiento: almacenados localmente, cifrados
- Historial de usuario: local por defecto, sync opcional con cifrado
- Nunca subir video a servidores sin consentimiento explícito opt-in
